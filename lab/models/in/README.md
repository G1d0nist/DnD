# Сюда — сырые модели из генератора

Кладите файл как есть (`.glb` лучше всего; можно `.fbx` или `.obj` с текстурами в одной подпапке).
Имя файла — по-английски, как существо: `goblin.glb`, `skeleton.glb`, `wolf.glb`.

Дальше обработка в Blender: чистка, ~10 000 треугольников, текстура 1024 px, скелет,
анимации (стойка, шаг, удар, получение урона, смерть) → готовый файл в `lab/models/`.
Сами сырые файлы в git не попадают (они большие).
