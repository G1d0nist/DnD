# Модели для этапа 0б

Положите сюда файлы `.glb` с этими именами — страница `lab/stage0b.html` подхватит их сама вместо заглушек:

| Файл | Существо | Рост на поле |
|---|---|---|
| `wizard.glb` | Илва, волшебница | ~1 клетка |
| `skeleton.glb` | Скелет | ~1 клетка |
| `ogre.glb` | Огр (Большой, 2×2) | ~2 клетки |
| `goblin.glb` | Гоблин (сделан в Blender, исходник `goblin.blend`; на сцене пока не используется) | ~0,9 клетки |

Масштаб и положение подгоняются автоматически: модель ставится на подставку и растягивается по высоте. Лицом модель должна смотреть вперёд (по оси +Z, как отдаёт большинство генераторов).

Желательно до ~10 000 треугольников и текстуры 1024 px — так файл будет около 1 МБ.
