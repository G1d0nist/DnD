# Модели для этапа 0б

Положите сюда файлы `.glb` с этими именами — страница `lab/stage0b.html` подхватит их сама вместо заглушек:

| Файл | Существо | Рост на поле |
|---|---|---|
| `wizard.glb` | Илва, волшебница | ~1 клетка |
| `skeleton.glb` | Скелет | ~1 клетка |
| `ogre.glb` | Огр (Большой, 2×2) | ~2 клетки |
| `goblin.glb` | Гоблин: модель из Hunyuan3D, раскраска по двум референсам, скелет и анимации (`idle`, `walk`, `attack`, `hit`, `death`). На столе подставляется всем существам с «гоблин» в имени. Старый самодельный исходник — `goblin.blend` | ~0,9 клетки |

| `wolf.glb` | Волк, Лютоволк, Ворг (по началу имени): модель из Hunyuan3D, раскраска по видам сбоку, спереди и сверху, четвероногий скелет и те же пять анимаций | ~0,62 клетки в холке и ушах, длина ~0,9 |
| `bandit.glb` | Бандит, Капитан бандитов: модель из Hunyuan3D, раскраска по видам спереди и сзади, скелет как у гоблина, удар ятаганом наотмашь с выпадом | ~1,05 клетки |

## Анимации

Объёмный вид стола (`table3d.js`) сам проигрывает клипы с такими именами, если они есть в `.glb`:
`idle` (стоит, по кругу), `walk` (идёт, по кругу, на месте), `attack` (удар или бросок, один раз),
`hit` (получил урон, один раз), `death` (падает и остаётся лежать — так же без сознания).
Модели без анимаций просто стоят, как раньше.

Масштаб и положение подгоняются автоматически: модель ставится на подставку и растягивается по высоте. Лицом модель должна смотреть вперёд (по оси +Z, как отдаёт большинство генераторов).

Желательно до ~10 000 треугольников и текстуры 1024 px — так файл будет около 1 МБ.

## Части фигурок персонажей

`pc_plate.glb` — тело в латах со скелетом и анимациями, `pc_head_*.glb` — головы, крепятся к кости `head`.
`wpn_*.glb` и `shield_*.glb` — оружие и щиты, собраны в Blender из примитивов скриптом `in/scripts/weapons.py`
(в git не попадает; рабочий файл `in/weapons_work.blend`). Все части выгружены в системе тела в позе покоя и
прицепляются к костям: оружие — к `hand.R`, луки — к `hand.L`, щиты — к `forearm.L`. Какое оружие брать, решает
`PC_WPN` в `table3d.js` по названию первой атаки персонажа; щит — круглый, при тяжёлом и среднем металлическом доспехе — геральдический.
`pc_anims.glb` — только скелет и общие движения фигурок сверх тех, что в теле: `shoot` (выстрел из лука), `shootx`
(из арбалета), `cast` (заклинание). Делаются скриптом `in/scripts/pcextra.py` в `in/weapons_work.blend`; `table3d.js`
добавляет их к клипам тела.
